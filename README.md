# ✈️ AeroPerf – Aircraft Performance Calculator

An interactive web-based aircraft performance calculator built with **HTML, CSS, and JavaScript**. AeroPerf helps aerospace engineering students and aviation enthusiasts estimate aircraft performance through a clean, responsive, and user-friendly interface.

---

## 🌐 Live Demo

👉 https://ashrafulrafsun10.github.io/AeroPerf-Aircraft-Performance-Calculator/

---

## ✨ Features

- ✈️ Aircraft Performance Calculator
- 📊 Instant Performance Results
- 🎨 Modern & Responsive User Interface
- ⚡ Fast Client-side Calculations
- 📱 Mobile-Friendly Design
- 💻 Lightweight Web Application
- 🚀 Beginner-Friendly Aerospace Tool
