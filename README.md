# AeroPerf

AeroPerf is a modern Flight Performance Calculator built with HTML, CSS and JavaScript.

## Features
- Apple Liquid Glass UI
- Aircraft Selection
- Airport ICAO Input
- Wind & Temperature Inputs
- Pressure Altitude
- Aircraft Weight
- Flight Performance Results
- Responsive Design

## Technologies
- HTML5
- CSS3
- JavaScript
